# CLIX

CLIX is an Android application for managing utility bills, meters, outages, and account settings.

## Features

- Login and authentication
- Dashboard overview
- Bill viewing and details
- Meter status and tracking
- Outage reports and tracking
- System notifications
- User settings

## Tech Stack

- Language: Kotlin
- UI Framework: Android XML Layouts and Material Design 3
- Build System: Gradle (Kotlin DSL)
- Minimum SDK: 24
- Target SDK: 35

## Getting Started

### Prerequisites

- Android Studio
- JDK 11

### Build and Run

1. Clone the repository:
   ```bash
   git clone https://github.com/muyeed15/clix-android.git
   ```

2. Open the project in Android Studio.

3. Build the project using Gradle:
   ```bash
   ./gradlew assembleDebug
   ```
